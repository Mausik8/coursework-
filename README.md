📋 Опис продукту
Консольний текстовий редактор у стилі "Блокнот", розроблений мовою програмування C/C++.
Програма працює в командному рядку Windows/Linux і дозволяє створювати, переглядати, редагувати та зберігати текстові файли без використання графічних бібліотек.
Мета проєкту: закріпити навички роботи з файлами, динамічною пам'яттю та структурами даних у вигляді масивів покажчиків.
